# ClimaXene 🌦️

An AI-powered hyperlocal climate intelligence platform that predicts flood risk using ensemble machine learning and MXene-inspired adaptive sensing principles.

## Key Features

* Flood early warning system
* 72-hour weather forecasting
* Explainable AI (SHAP)
* Historical disaster validation
* Interactive climate dashboard
* Responsible AI bias auditing

## Tech Stack

* Python
* Streamlit
* Scikit-Learn
* Pandas
* SHAP
* OpenWeather API

## Impact

ClimaXene helps governments, disaster-response agencies, farmers, and smart cities prepare for extreme weather events before they occur.
